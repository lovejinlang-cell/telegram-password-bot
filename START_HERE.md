## 🆘 Need Help?

### Bot មិនដំណើរការ locally?
1. ពិនិត្យ `.env` file មាន token ត្រឹមត្រូវ
2. Run: `pip install -r requirements.txt`
3. សាកល្បងម្តងទៀត: `.\run_bot.ps1`

### Deployment issues?
1. Read `RENDER_SETUP.md` carefully
2. Check Render logs for errors
3. Verify `TELEGRAM_BOT_TOKEN` environment variable

### Bot responds slowly?
- Normal on free tier! First message = 30 sec delay
- Next messages = instant ⚡
